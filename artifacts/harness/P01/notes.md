# P01 Codex 직접 보정 노트

## 보정 범위
1. **레퍼런스 무결성 검증 강화**:
   - 32개 파일 ID, SHA-256, 크기, 확장자, 익명 파일명, 상대경로, 스캔 상태를 고정 기대값과 비교합니다.
   - 9개 인벤토리 폴더와 분류 키를 기계적으로 조인하고 primary/secondary 값이 `TYPE-01`~`TYPE-06` 범위인지 검증합니다.

2. **계약 문서 정합성 보정**:
   - 실제 08번 폴더명 `08. 돌관공사비`를 식별키로 사용하고 `08. 물량공사비`는 명세 별칭으로 분리했습니다.
   - 존재하지 않는 `SCENARIO-13`, `SCENARIO-14` 참조를 제거하고 12개 정상·2개 실패 시나리오에 연결했습니다.
   - 원본 업무 프로세스 문서의 실제 저장소 경로를 기록했습니다.

3. **보안 보고서와 도구 재현성 보정**:
   - 실제 확장자 구성인 HWP 13, HWPX 3, PDF 15, XLSX 1과 스캔 상태를 정확히 기록했습니다.
   - 인벤토리 도구의 특정 PC 절대경로를 제거하고 저장소 기준 상대경로를 사용합니다.
   - 스캔 도구는 원본 파일명을 출력하지 않고 익명 ID·확장자·크기·해시만 출력합니다.

4. **남은 보안 운영 항목**:
   - 과거 Git 커밋에 존재하는 비익명 인벤토리 제거는 이력 재작성과 원격 강제 갱신이 필요한 파괴적 작업입니다.
   - 보안·데이터 책임자의 승인 전에는 임의로 수행하지 않으며, 승인 후 별도 보안 절차로 처리해야 합니다.
