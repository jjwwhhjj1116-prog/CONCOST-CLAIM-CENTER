# P02 Stitch UX/UI Design 구현 및 Codex 보정 노트

## 주요 검증 및 구현 내역
1. **20개 전수 화면 보정 및 6대 클레임 고정 유형 반영**:
   - `AUTH-01` ~ `RESP-01` 20개 화면을 유지하고 `docs/stitch/stitch-master-prompt.md` 및 화면 명세에 `TYPE-01`~`TYPE-06` 6개 고정 클레임 업무 유형 단일 소스 정의.
   - `docs/보고서 템플릿/` 9개 폴더는 업무 유형이 아닌 실무 레퍼런스 원본 묶음으로 취급함.

2. **DASH-01 대시보드 10초 인지 테스트 및 2클릭 행동 보장**:
   - 6대 핵심 KPI 지표 수록 (진행 사건, 오늘 마감, 오늘 할 일, 작성중 문서, 지연 업무, 미수 성공보수).
   - 4개 주요 빠른 실행 버튼 수록 (`[새 사건 등록]`, `[제안서 작성]`, `[보고서 작성]`, `[자료 업로드]`).

3. **REPO-02 보고서 스튜디오 3단 구조 및 시각적 상태 가시성 보장**:
   - 좌(목차/상태), 중(에디터/상태노드), 우(근거/AI/상태노드) 3단 레이아웃 유지.
   - Normal, Loading, Empty, Error, 403 Forbidden 5가지 화면 상태가 자바스크립트 `setUIState` 스위처를 통해 시각적으로 전환 가능.

4. **1024px 반응형 레이아웃 및 접근성 보장**:
   - 1024px 축약 시 드로어 열기/닫기 (`#drawerToggleBtn`, `#closeDrawerBtn`) 자바스크립트 이벤트를 완벽히 작동시켜 드로어 복구 가능.
   - 포커스 링, ARIA 속성, 엘립시스 텍스트 오버플로우 스타일 수록.

5. **P01 회귀 보호 복원**:
   - P02 작업 중 축소됐던 P01 검사를 복원하여 32개 원본의 정확한 ID/SHA-256/크기/확장자/익명화 경로, 9개 레퍼런스 폴더 분류, 33개 엔터티, 12개 정상·2개 실패 시나리오, Reviewer RBAC, P01 manifest를 계속 검증합니다.

6. **실행 가능한 P02 의미 검증과 적대 반례 7종**:
   - 단순 키워드·파일 크기 확인을 보조 수준으로 낮추고, 정확한 화면·page-spec 집합, DOM 역할, 상태 노드와 실제 전환식, 1024px 이벤트, 접근성 이름·포커스 CSS, 디자인 토큰, 6대 유형/9개 레퍼런스 경계를 검증합니다.
   - 화면 누락, `TYPE-07`, 템플릿 폴더의 유형 승격, 3단 구조 제거, 드로어 이벤트 제거, 403 전환 제거, 포커스 규칙 제거를 각각 격리된 메모리 복제본에 적용했을 때 검증기가 모두 거부하는지 자동 확인합니다.

7. **Codex 직접 보정**:
   - `component-map.md`의 대시보드 질문 수를 7개에서 계약상 6개로 정정했습니다.
   - `stitch-master-prompt.md`에 9개 폴더가 유형이 아닌 레퍼런스 묶음이라는 금지 규칙을 추가했습니다.
   - REPO-02에서 로딩·빈 상태·오류 시 우측 AI 패널 상태가 부모 숨김으로 가려지던 문제를 고치고, 드로어 닫기 버튼과 403 모달의 접근성 의미를 보강했습니다.
