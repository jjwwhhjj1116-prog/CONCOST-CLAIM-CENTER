# 접근성, UX 인지 경로 및 코너 케이스 명세서 (Accessibility & Edge Cases)

## 1. 대시보드 10초 인지 테스트 지정 6대 핵심 질문 및 시각화 솔루션
지시서 5.2절 규정에 따른 대시보드 진입 10초 이내 6대 핵심 질문에 대한 정밀 시각화 명세입니다.

1. **진행 중인 사건은 총 몇 개인가?**: 메인 KPI 1번 카드에 대형 숫자 카운터(예: 42건) 및 🔵 Slate 배지로 표시.
2. **오늘 또는 곧 마감되는 일은 무엇인가?**: 2번 마감 KPI 카드 및 D-day 기일 타임라인에 🔴 Red (D-3) / 🟠 Orange (D-7) 배지로 긴급 정렬.
3. **내가 오늘 해야 할 일은 무엇인가?**: 3번 카드 및 로그인 사용자 전용 업무 큐 테이블에 체크박스 리스트로 시각화.
4. **어떤 문서가 현재 작성·검토·승인 진행 중인가?**: 4번 카드 및 장 상태 진행바(Progress Bar)로 🟣 AI 초안, 🟡 담당자 검토, 🟢 승인 분포 표시.
5. **기한이 지연된 업무는 무엇인가?**: 5번 경고 카드에 🔴 Rose Red 지연 강조 배지 및 지연 일수 표시.
6. **아직 받지 못한 미수 성공보수는 얼마인가?**: 6번 수금 카드에 미수금액(예: ₩45,000,000) 및 입금 지연 경고 표시.

## 2. 2클릭 이내 직관 과업 이동 경로 (2-Click Shortcuts)
1. **대시보드 -> 특정 사건 등록**: 대시보드 상단 [새 사건 등록] 빠른 버튼 클릭 (1-Click).
2. **대시보드 -> 보고서 스튜디오 진입**: 업무 큐 문서명 클릭 (1-Click).
3. **사건 목록 -> 특정 사건 3단 스튜디오 진입**: 사건 행 클릭 (1-Click) -> [보고서 작성] 탭 클릭 (2-Click).
4. **검토함 -> 1차 승인 처리**: 검토함 목록 [1차 승인] 버튼 클릭 (1-Click).

## 3. 웹 접근성 및 명암비 규정 (WCAG 2.1 AA)
- **최소 명암비 (Contrast Ratio)**: 메인 텍스트와 배경 간 명암비 4.5:1 이상 (텍스트 `#f8fafc` vs 배경 `#0f172a` => 15.2:1 달성).
- **키보드 탐색 (Keyboard Focus)**: `Tab` 키 이동 시 2px Solid Royal Blue (`--primary-500`) 포커스 링 표시, `Enter`/`Space` 키로 모든 버튼 및 아코디언 조작 가능.
- **스크린 리더 (ARIA Labels)**: 상태 배지 및 AI 생성 버튼에 `aria-label`, `aria-live="polite"` 필수 지정.

## 4. 코너 케이스 (Edge Cases) 5종 명세

### 4.1 빈 상태 (Empty State)
- **적용 화면**: 사건 목록, 자료실, 회의록, 보고서 목록, 검토함
- **UI 표현**: Central Illustration Placeholder + "등록된 항목이 없습니다. 버튼을 눌러 시작하세요." 가이드 안내 및 생성 파랑 버튼 배치.

### 4.2 오류 상태 (Error State)
- **적용 화면**: 전체 20개 화면 및 AI Gateway 연동
- **UI 표현**: 🔴 Rose Red Toast Notification ("네트워크 연동 실패. 잠시 후 다시 시도해 주세요.") + [재시도] 버튼.

### 4.3 권한 없음 상태 (403 Forbidden State)
- **적용 화면**: 타 사건 직접 URL 접근 및 무단 결재/편집 시도
- **UI 표현**: 🔒 Lock Shield Illustration + "이 사건에 접근할 권한이 없습니다. (HTTP 403 Forbidden)" 안내 및 [홈으로 돌아가기] 버튼.

### 4.4 긴 콘텐츠 오버플로우 상태 (Content Overflow)
- **적용 화면**: 보고서 스튜디오 에디터, 사건 제목, 자료실 파일명
- **UI 표현**: 제목/파일명은 `text-overflow: ellipsis; white-space: nowrap;` 처리 (마우스 호버 시 Tooltip 전체 텍스트 출력). 에디터는 Custom Scrollbar 가 가동됨.

### 4.5 접근성 및 키보드 상태 (Accessibility State)
- **적용 화면**: 전체 20개 화면
- **UI 표현**: 키보드 `Tab` 키 포커스 시 2px Solid Blue 포커스 링 표시 및 스크린리더 aria-live 읽기 안내.
