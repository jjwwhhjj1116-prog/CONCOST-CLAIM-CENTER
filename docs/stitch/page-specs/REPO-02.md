# REPO-02: 보고서 스튜디오 (3단 구조) 화면 명세서

## 1. 화면 개요 및 목적
보고서를 7대 정규 장(Section)별로 작성, 선택된 근거자료 기반 AI 초안 생성, 검토, 1차 승인 및 잠금을 수행하는 3단 핵심 스튜디오 화면입니다.

## 3. 1440px 데스크톱 레이아웃 & 3단 컴포넌트 패널 슬롯
- **좌측 패널 (260px)**: 보고서 장(Section) 목차 트리, 7대 표준 장 상태 배지 (⚪ 미작성, 🔵 작성중, 🟣 AI초안, 🟡 담당자검토, 🟠 수정요청, 🟢 승인, 💎 최종확정), 작성자 프로필
- **중앙 패널 (Flex)**: 구조화 리치 텍스트 에디터, 문단별 근거자료 링크 하이라이트, 이전 버전 이력 비교, 자동/수동 저장 전환 스위치
- **우측 패널 (320px)**: 사건 증거 문서 선택 체크박스 목록, AI 공급자/모델 선택 드롭다운, [AI 초안 생성] 그라데이션 버튼, 검증 플래그 ([확인 필요], [숫자 검증 필요]) 목록

## 4. 1024px 태블릿 축약 레이아웃
- 좌측 목차가 아이콘 툴바로 접히며, 우측 AI 패널이 바텀 시트 슬라이드 오버 Drawer 로 유연 전환됨.

## 5. 비주얼 배지 & UI 인터랙션
- **상태 전환 인터랙션**: `AI 초안` 상태 장은 검토자 승인 후 `승인` 배지로 바뀌며 본문 리치 에디터가 편집 잠금 처리됨.

## 6. 코너 케이스 6종 명세
- **로딩 상태 (Loading State)**: [AI 초안 생성] 버튼 클릭 시 우측 패널에 보라색 스파클링 펄스 애니메이션 및 에디터 영역 스켈레톤 로딩 마스크 표시.
- **빈 상태**: 근거 자료 미선택 후 [AI 초안 생성] 시 "근거 증거를 1건 이상 선택하세요" 경고 팝업 및 생성 차단.
- **오류 상태**: AI 환각 발생 시 `[근거자료 없음]` 플래그가 자동 부여되고 `승인` 전환이 차단됨.
- **403 권한 없음**: 검토자 권한자가 본문 직접 편집 시도 시 "본문 수정 권한이 없습니다 (댓글만 가능)" 차단.
- **긴 콘텐츠 오버플로우**: 긴 본문은 커스텀 스크롤바 처리되며 에디터 높이 자동 조절.
- **접근성 및 키보드 탐색**: 에디터 내 `Ctrl+S` 수동 저장 숏컷, Tab 키로 패널 간 이동 지원.
