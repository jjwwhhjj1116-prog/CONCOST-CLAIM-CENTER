# AI-01: AI 공급자 및 비용 설정 화면 명세서

## 1. 화면 개요 및 목적
5개 멀티 AI 공급자(Ollama, OpenAI, Anthropic, Gemini, DeepSeek) 연동 및 월 비용 제한 한도를 설정하는 관리 화면입니다.

## 3. 1440px 데스크톱 레이아웃 & 컴포넌트 슬롯
- **공급자 카드 그리드**: 5개 공급자별 연결 상태 배지(Connected/Disconnected), API키 암호화 마스크 입력창, [연결 테스트] 버튼, 사용 모델 드롭다운
- **비용 한도 조절**: 사용자별/월별 토큰 비용 한도 슬라이더 위젯

## 4. 1024px 태블릿 축약 레이아웃
- 3열 공급자 카드가 2열 카드로 유연 전환.

## 5. 코너 케이스 6종 명세
- **로딩 상태 (Loading State)**: AI 공급자 헬스체크 수행 시 카드별 스피너 로더 표시.
- **빈 상태**: API키 미입력 시 [연결 테스트] 버튼 비활성화.
- **오류 상태**: API키 검증 실패 시 🔴 Rose Red 연결 오류 알림.
- **403 권한 없음**: 관리자가 아닌 사용자의 AI 설정 진입 시 HTTP 403 차단.
- **긴 콘텐츠 오버플로우**: 긴 API 키 문자열 마스킹(••••••••) 처리.
- **접근성 및 키보드 탐색**: 슬라이더 키보드 좌우 방향키 조작 지원.
