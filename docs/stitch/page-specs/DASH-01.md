# DASH-01: 메인 대시보드 화면 명세서

## 3. 1440px 데스크톱 레이아웃 & 6대 질문 시각화 슬롯
- **상단 툴바**: 글로벌 통합 검색바, 4대 빠른 실행 버튼 ([새 사건 등록], [제안서 작성], [보고서 작성], [자료 업로드])
- **대시보드 10초 인지 테스트 지정 6대 핵심 질문 슬롯**:
  1. **진행 중인 사건은 총 몇 개인가?**: 1번 KPI 카드에 대형 카운터 숫자(42건) 및 🔵 Slate 배지 표기
  2. **오늘 또는 곧 마감되는 일은 무엇인가?**: 2번 KPI 카드 및 기일 타임라인에 🔴 Red (D-3) / 🟠 Orange (D-7) 긴급 배지 정렬
  3. **내가 오늘 해야 할 일은 무엇인가?**: 3번 카드 및 담당자 전용 업무 큐 체크박스 리스트 시각화
  4. **어떤 문서가 현재 작성·검토·승인 진행 중인가?**: 4번 카드 및 장 상태 진행바(Progress Bar)로 🟣 AI 초안, 🟡 담당자 검토, 🟢 승인 분포 표시
  5. **기한이 지연된 업무는 무엇인가?**: 5번 경고 카드에 🔴 Rose Red 강조 배지 표시
  6. **아직 받지 못한 미수 성공보수는 얼마인가?**: 6번 수금 카드에 미수금액(₩45,000,000) 및 입금 지연 경고 표시

## 4. 1024px 태블릿 축약 레이아웃
- KPI 카드가 3열 2행 그리드로 유연 재배치되며, 우측 업무 큐 패널이 하단으로 이동하여 수직 스크롤 배치됨.

## 5. 비주얼 배지 & UI 인터랙션
- **2클릭 과업 이동 경로**: 대시보드 퀵 버튼 클릭 시 즉시 해당 과업 페이지로 1~2클릭 내 직관 이동.

## 6. 코너 케이스 6종 명세
- **로딩 상태 (Loading State)**: 데이터 수신 중 6개 KPI 카드에 반투명 펄스(Pulse) 스켈레톤 로더 표시.
- **빈 상태**: 사건 및 일감이 하나도 없을 때 "등록된 사건이 없습니다. [새 사건 등록]을 누르세요" 가이드 표시.
- **오류 상태**: 대시보드 KPI 로딩 실패 시 🔴 Rose Red Toast 경고 및 [재시도] 버튼 제공.
- **403 권한 없음**: 비인가 영역 클릭 시 "권한이 없습니다 (HTTP 403)" 모달 안내.
- **긴 콘텐츠 오버플로우**: 긴 사건명은 text-overflow: ellipsis 처리, 마우스 호버 시 툴팁 출력.
- **접근성 및 키보드 탐색**: WCAG AA 명암비 15.2:1 준수, Tab 키 순차 탐색 2px Blue 포커스 링 표시.
