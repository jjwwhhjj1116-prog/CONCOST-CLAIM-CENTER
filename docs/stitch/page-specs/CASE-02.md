# CASE-02: 새 사건 등록 화면 명세서

## 1. 화면 개요 및 목적
신규 수임 사건의 명칭, 대/중/소분류 카테고리, 담당자 정보를 수집하는 단계형 위자드 모달 화면입니다.

## 2. Google Stitch Screen Metadata
- **Stitch Project ID**: `proj_claim_studio_v1`
- **Stitch Screen ID**: `screen_case_02`
- **Stitch Official URL**: `https://stitch.withgoogle.com/projects/proj_claim_studio_v1/screens/screen_case_02`
- **Export Artifacts Path**: `docs/stitch/artifacts/CASE-02/screen.html`

## 3. 1440px 데스크톱 레이아웃 & 컴포넌트 슬롯
- **스텝퍼 모달 (640px)**: Step 1 (기본정보) -> Step 2 (대/중/소분류 지정) -> Step 3 (담당 PM 배정)
- **입력 슬롯**: 사건명, 사건코드, 대분류(건설)-중분류(하자보수)-소분류(균열) 카스케이딩 셀렉터
- **액션 슬롯**: [취소], [이전], [다음], [사건 등록 완료] 버튼

## 4. 1024px 태블릿 축약 레이아웃
- 모달 폭 520px로 유연 축소, 스텝퍼 텍스트가 번호 아이콘으로 축약 표시.

## 5. 비주얼 배지 & UI 인터랙션
- **인터랙션**: 분류 선택 시 하위 분류가 애니메이션 슬라이드 릴리즈됨.

## 6. 코너 케이스 6종 명세
- **로딩 상태 (Loading State)**: 카테고리 트리 수신 및 저장 시 모달 내부 프로그레스 바 표시.
- **빈 상태**: 입력 폼 초기화 상태 시 [다음] 버튼 비활성화.
- **오류 상태**: 중복 사건코드 입력 시 입력창 붉은 포커스 및 "이미 존재합니다" 메시지.
- **403 권한 없음**: 실무자가 사건 등록 시도 시 "권한이 없습니다 (HTTP 403)" 경고.
- **긴 콘텐츠 오버플로우**: 긴 사건명 입력 시 입력창 세로 높이 자동 확장.
- **접근성 및 키보드 탐색**: Esc 키로 모달 닫기, Tab 키 포커스 순회 준수.
