# 보고서 작성용 단기·장기기억 아키텍처

## 결정

현재 Cloudflare 검증 환경은 D1을 기억 원장으로 사용하고 `MemoryAgent` 인터페이스 뒤에
`D1_HERMES_COMPATIBLE_V2` 규칙 엔진을 둔다. 공식 Hermes Agent 전체 런타임을
Cloudflare Worker 번들에 포함하지 않는다.

공식 Hermes Agent는 Python 기반의 독립 실행 에이전트이며 MIT 라이선스다. 추후 베트남
공유 서버가 준비되면 공식 런타임을 별도 프로세스로 설치하고, HTTPS/VPN으로 보호된
사내 Memory Bridge를 통해 현재 `MemoryAgent` 인터페이스의 구현체만 교체한다.

- 공식 저장소: https://github.com/NousResearch/hermes-agent
- 공식 문서: https://hermes-agent.nousresearch.com/docs/

## 현재 동작

### 단기기억

- 현재 사건, 현재 챕터, 현재 사용자 경계만 사용한다.
- 현재 저장된 사람 수정본 중 선택한 챕터만 포함한다.
- 다른 사건의 본문, 대화 기록 전체, API 키, 원본 파일 내용은 포함하지 않는다.
- 컨텍스트는 최대 12,000자로 제한하고 SHA-256과 항목 수만 사용 원장에 남긴다.

### 장기기억

`AI 초안 → 사람 수정·저장 → 피드백 → 구조화 후보 → 관리자 승인`을 거친 규칙만 사용한다.
검색 우선순위는 `챕터 → 클레임 유형 → 보고서 유형 → 개인 → 회사 전체`이며 한 생성에
최대 8개만 주입한다. 반려·비활성 규칙은 검색에서 제외한다.

### 증거 원장

각 생성은 다음을 append-only로 기록한다.

- 사용한 메모리 엔진 버전
- 단기기억 컨텍스트 SHA-256과 항목 수
- 장기기억 항목 수와 적용 범위
- 실제 사용한 승인 메모리 ID
- 생성 ID, 사건, 챕터, 사용자, 시각

## 외부 Hermes 전환 조건

1. 사내 공유 서버와 영속 볼륨이 준비되어야 한다.
2. Hermes 프로세스는 인터넷에 직접 공개하지 않고 VPN 또는 인증된 사내 Bridge 뒤에 둔다.
3. D1의 후보·승인·비활성·사용 원장을 계속 최종 권한 원장으로 유지한다.
4. 외부 런타임은 후보 분석과 검색 순위만 제안하며 자동 승인하지 않는다.
5. 사건 원문 대신 최소화된 구조화 규칙만 전송하고 tenant/case/user 범위를 요청마다 검증한다.
6. timeout 시 D1 호환 엔진으로 fail-closed하거나 기억 없이 생성하며, 외부 응답을 자동 저장하지 않는다.

## 금지사항

- 채팅 이력 저장을 장기기억이라고 표시하지 않는다.
- 과거 보고서를 매번 전부 프롬프트에 넣지 않는다.
- 관리자 승인 전 조직 공통 규칙으로 승격하지 않는다.
- 한 사용자의 개인 기억을 다른 사용자에게 적용하지 않는다.
- 기억 규칙을 사건의 사실 근거로 취급하지 않는다.
