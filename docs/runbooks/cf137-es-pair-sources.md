# CF137 기계경비·표준시장단가 자동연동

대상: development 테스트서버만. 시작 브랜치 `feat/CF123-es-v2`, SHA `4d86e33`.

## 사용자 요청과 원인

- 자동조회 미매칭 기계경비·5개 분야 표준시장단가 연결 및 계산 중단 원인 수정.
- 사용자는 산업안전 ‘조건 2’ 지정을 철회했다. 기존 C22 1.86% 및 조건부 수동 입력을 유지하며 임의 요율을 만들지 않는다.
- 원본 가져오기의 K0 이력은 2021~2025년까지만 있다. 조정일을 2026년으로 바꾸면 미존재 기간쌍이 비어 계산이 멈춘다. 비목 14의 기계경비 금액은 가중치 입력이지 공통기종 수·손료 평균이 아니다. 빈값을 0/1/100으로 대체하지 않았다.

## 구현

- 신규 로그인·ES 역할 보호 GET `/api/es/sources/pairs`. Worker와 Node 어댑터 공통 수집기를 연결. DB·키 읽기/쓰기·migration 없음.
- CAK 2023~2026 공식 PDF의 표지 연도, 33페이지, p4~29 열 위치·단위·분류번호·행 수·중복을 검증. p30~33 승무원 부록은 제외. PDF.js 텍스트 좌표로 구매가격(천원)과 시간당 손료(원)를 구별; 연료 문자가 같은 텍스트 조각에 합쳐진 경우도 손료 첫 숫자만 읽는다. 자원은 성공·오류 모두 finally에서 해제.
- 공통 분류번호이며 양쪽 가격이 양수인 기종만 집계. 손료 합계/공통 수를 정수 절사한다. 규격 문구가 다른 기존 기종을 임의 삭제하지 않으며 양쪽 규격 원문을 검토 근거에 보존한다. 분류번호 기준 자동 대조는 공식 동일성 승인과 다르다.
- PPS 2023~2026 분야별 공표·정정본 23개 항목 catalog. 파일 제목이 아닌 공종별 기준일 C/비교일 H를 정확히 대조한다. 공통수 E/J, 합계 F/K, 평균 G/L을 검증; 전체품목수 D/I와 혼동하지 않는다. `총괄표`의 `A1:L500`만 배열로 펼쳐 과도한 사용범위로 인한 메모리 증가를 제한한다.
- 원문은 고정 HTTPS catalog, 최대15초·5MB·동일 경로의 제한적 주소 전환으로 읽는다. 요청 내 파일 재사용, 원문 SHA256·URL·공표기간·규격 차이를 pair.source에 보존. 사용자 원본과 공식 첨부파일은 저장소에 추가하지 않음.
- `xlsx` 0.20.3(공식 SheetJS 배포), `unpdf` 1.8.1 추가. 자체 BIFF/PDF 디코더 대신 라이브러리 사용. Node 실행환경은 unpdf 요구조건인22이상 필요. 브라우저 프런트엔드에는 두 파서가 포함되지 않는다.
- 기존 확인창에 현재/직전 12기간쌍 비교, 출처·규격 변경, 기존 기간쌍 유지 추가. 응답 전체 검증 후에만 후보 반영; 확인 전 입력/DB 변경 없음. 적용 후 기존 undo/redo·저장·계산 유지.
- 원자료 화면 평균은 금액(원)·천단위 쉼표. 수동 수정 시 과거 자동 집계 합계 메타데이터를 제거하고 수정 근거를 남긴다. 오류의 ‘원자료 확인’은 누락 기간쌍 입력칸으로 이동하며 ‘요율정보 가져오기’도 직접 실행 가능.
- Ponytail 최소 변경, Impeccable clarify/UI-UX 오류 회복 원칙 적용. 기존 화면 구성·계산식·17시트 출력 템플릿 보존.

| 대상 | 공통 수 | 기준 합계 / 평균 (원) | 비교 합계 / 평균 (원) |
| --- | ---: | ---: | ---: |
| 원본 K0 2023→2025와 공식 PDF | 608 | 35,531,001 / 58,439 | 38,140,494 / 62,731 |
| 공식 PDF 2023→2026 | 607 | 35,521,373 / 58,519 | 39,223,932 / 64,619 |

- 원본 2023→2025 지수107.34까지 독립 대조 일치. 초기 인수패키지 원본과 최근 재첨부 `(확인).xlsx`는 파일 전체 SHA는 다르지만 K0의 위6개 집계 결과는 모두 일치한다. 두 파일 모두 literal을 Decimal로 집계했으며 수식 캐시에 의존하지 않았다. 원본 SHA 전후 불변.
- PDF 연도별 행 수: 2023 608, 2024 610, 2025 611, 2026 613. 모든 연도 파싱 성공. 2023→2026 동일 분류번호 중 규격 문구 변경10종(단위/규격 포함)은 확인창 근거에서 검토 필요.
- 2023-11-15→2026-04-03(직전04-02도 동일 공표기간) PPS 기대값: 토목1215개 598212→680163, 건축306개42070→46708, 기계설비289개71129→78567, 전기640개1774823→1946223, 통신411개193455→213282. 독립 원문 XLS/XLSX 대조 일치. 토목 기준은2023-05-10 정정본, 전기 비교는2026-03-10이다.
- 공통기종 원칙 참고: 정부 입찰·계약 집행기준 제70조⑤ https://law.go.kr/admRulLsInfoP.do?admRulSeq=2100000196210 . 특정 계약의 법적 적용 승인으로 사용하지 않는다.

## 남은 검증·제한과 다음 시작점

- 새 공표본 자동 발견/catalog 갱신은 미구현. 확인 종료일2026-09-10 이후 날짜와 미연결 과거 기간은 현재 수치로 추정하지 않는다.
- 산업안전 조건표 자동 확정, 복수차수/복수선금 확대는 범위 밖. 기계 규격 변경10종은 담당자의 원문 검토가 필요하다.
- Node 서버는 코드/합성검증만 수행, 실제 배포하지 않았다. 실제 프린터·원본 Excel 앱 재계산·전체 출력 시각 재대조는 이번 검수 범위 밖이다.
- 기존 사용자 문서는 수정하지 않는다. 특히 과거 CF136 검수ID `1761cba0-6f69-481f-9ee5-5d037d3187f6`은 이제 사용자가 이름·내용을 바꾼 실제 작업자료이므로 합성 테스트 대상으로 다시 쓰거나 삭제하지 않는다.
- 사용: 입력 저장 → 테스트서버 새로고침 → 기준일 확인 → ES 요율정보 가져오기 → 기간쌍/규격 변경 검토 → 확인·입력에 적용 → 저장·계산.
- 롤백은 시작 SHA `4d86e33` 또는 이전 development 배포 `917c1dff-8477-4632-81d7-1a988227182e`. DB 복구/변경 불필요.
