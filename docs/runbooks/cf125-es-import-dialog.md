# CF125 ES Excel 가져오기 확인 팝업

2026-09-09. 대상은 development 테스트 서버만이며 DB, 비밀키, 가오픈·베트남 서버는 변경하지 않는다.

## 변경

- 상단 Excel 가져오기/Excel 내보내기 버튼 분리. 가져오기는 파일 선택, 내보내기는 출력 탭으로 이동한다.
- 파일 선택 직후 중앙 네이티브 dialog에서 진행 상태와 현재/가져올 값 비교를 표시한다.
- 계약정보·28개 비목 상세 비교와 파서 검수 안내를 펼쳐 볼 수 있다.
- 취소/Escape는 기존 입력을 유지한다. 저장 중 닫기·중복 요청은 차단한다.
- 가져온 내용을 직접 기존 POST/PUT 저장 API로 보내고 성공 응답 후에만 입력·버전·화면을 갱신한다. 실패하면 팝업과 기존 입력을 유지한다.
- 서버 응답 유실 시 저장 여부는 불확실할 수 있으므로 목록에서 확인하도록 안내한다. 자동 재전송하지 않는다.

## 검증

- 파서 30건, 출력 8건, CF124 UI 계약 6건, CF125 실제 핸들러 계약 11건: 55건 통과.
- 실제 TS 핸들러와 mock API로 POST/PUT, 중복 저장, 지연, 409/403/timeout, 파싱 실패, 정규화 응답 반영 검증.
- 원본 SHA 유지, 파서 외부 요청 0.
- 실제 App 격리 브라우저에서 취소/Escape, 저장 1회, 503 재시도, 409 보존, Tab 순환, 모바일·다크 화면 확인.
- `corepack.cmd pnpm cf:build`: 타입 검사 및 Vite 빌드 통과. 기존 대형 chunk 경고는 남아 있다.
- development Wrangler dry-run 통과.

로컬 브라우저 증거: `output/playwright/es-v2/cf125-import-results.json`, `cf125-import-desktop.png`, `cf125-import-mobile-dark.png`. 합성 자료를 사용했으며 고객 원본·화면·키는 커밋하지 않는다.

## 범위와 한계

이번 검수는 가져오기 UX 및 저장 연계 변경 범위다. ES 전체 계산 승인, Excel 자체 재계산 및 실프린터 대조 완료를 의미하지 않는다. 격리 mock API 검수와 배포 서버 확인은 구분한다. 실제 사용자 산출서를 가져오기로 덮어쓰는 배포 검수는 수행하지 않는다.

## 배포

코드 빌드 후 `wrangler.development.jsonc` 대상으로만 배포하고, 배포 버전 및 공개 asset SHA 검증 결과를 이 문서에 후속 기록한다. migration 없음.
