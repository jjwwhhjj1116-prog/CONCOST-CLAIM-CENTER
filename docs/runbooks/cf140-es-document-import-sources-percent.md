## 구현과 근거

- `계약서·원가 가져오기`는 기존 전체 ES Excel 복원과 별도. 원가표 XLS/XLSX는 기존 SheetJS로 브라우저에서 직접 읽는다. 원본 수식은 실행하지 않고 저장된 계산값과 셀 근거를 제시한다. 기존 비용/메타/원자료를 일괄 교체하지 않으며 확인된 체크 항목만 화면에 적용한다. 저장은 기존 저장 버튼으로 한다.
- 실제 첨부 원가 3개 검증: 총괄 K, 당초 D/변경 E, 당초 L/변경 T를 선택 후보로 얻었고 각 열에서 14비목을 읽었다. 총괄/세부/숨김/차액 중복 합산 없음. 원본 해시 전후 동일. 고객 이름/금액은 소스·합성 테스트에 넣지 않았다.
- 직접재료비 합계에는 광산품/공산품/표준시장단가 구분이 없다. 이를 임의 배분하지 않고 미분류 근거로 노출한다. 모든 28비목이 자동 입력되는 기능으로 표현하면 안 된다. 미선택 기존 금액은 유지되므로 사용자가 해당 계약의 재료 내역과 대조해야 한다.
- XLSX는 압축 해제 전 100MB 누계/단일30MB/5000entry/위험 경로/매크로/embedding/실제 workbook ContentType 검사. 시트100개 및 !fullref500행 한도. 원본/변경·총액 중복은 자동 확정하지 않는다.
- PDF 3개는 27/39/8쪽 전체 스캔, 추출 텍스트 0자. 단순 PDF 텍스트 파서로 인식할 수 없다. Gemini native PDF 인식 경로를 기존 조직 공용키/유료·학습 미사용 정책과 함께 재사용했다. https://ai.google.dev/gemini-api/docs/document-processing
- Cloudflare `GET/POST /api/es/import/contract`: 로그인·ES역할·CSRF/동일 출처·정책·명시 동의·PDF MIME/signature/20MB 및 multipart 스트림 상한 검사. UI는 GET 정책 확인 전 파일을 보내지 않는다. 원문/결과 DB 저장 없음. JSON 후보를 서버/브라우저에서 동일 검증하고 금액·날짜·페이지·인용·VAT/당초변경을 확인한다. 계약일/입찰공고일을 입찰일로 대체하지 않는다. 사용자 체크 전 후보는 미적용.
