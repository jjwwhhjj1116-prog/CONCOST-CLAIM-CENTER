# CF128 ES 원본 출력 서식 검수

2026-09-09. 대상은 development 테스트 서버만이며 계산식·DB·권한·회사 API 설정은 변경하지 않는다.

## 수정

- 원본 `목록!C5:C9`를 붙임 1~5 제목의 단일 기준으로 사용한다. 원본의 `조정율`, `직하조정율` 문구도 임의 교정하지 않는다. 종합의견서 첨부 순번은 원본처럼 숫자를 사용한다.
- 목록도 원본 셀·열너비·행높이·여백으로 출력한다. 선택하지 않은 붙임 그룹은 목록에서 제외한다.
- 목록의 셀 밖 그룹 도형(‘붙임자료 목록’ 18pt 제목 상자와 외곽선)을 복원한다. XLSX는 개인정보 없는 도형 XML과 관계를 포함하며, 웹은 원본 셀 앵커·도형 좌표를 SVG로 표시한다. 원본 전체 파일/고객 입력/수식 캐시는 포함하지 않는다.
- Excel의 원화·경과일 리터럴, 3자리 구분, 음수 회계 형식, 0원, 백분율, 날짜 형식을 웹에서 표시한다. 저장값과 계산값은 표시 서식으로 변경하지 않는다.
- 원본 shrinkToFit 셀은 실제 글자 폭·높이를 측정해 축소한다. 단순 비율 적용 후 글꼴 힌팅 때문에 남던 넘침도 실측 후보 탐색으로 처리한다.
- 병합 셀의 외곽 테두리를 병합 범위 끝 셀에서 복원한다.
- 출력 XLSX는 원본의 시트별 배율(96/87/90/100%), 여백, 가로 중앙 정렬, A4, 원래 바닥글을 보존한다. 일괄 fitToPage/fitToWidth/fitToHeight 및 임의 머리글을 삽입하지 않는다.
- 미리보기와 인쇄는 같은 HTML/CSS를 사용하며 앱 입력화면 CSS와 iframe으로 분리한다. 화면 폭 맞춤 축소는 화면에만 적용하고 인쇄는 210×297mm를 유지한다.
- 검토용 초안/LEGACY_REPLAY 상태는 출력 작업화면에 명시한다. 출력 승인·저장 run·선택 페이지·이력 API 검사는 유지한다. 실제 프린터 성공을 자동으로 주장하지 않는다.

## 실행 검증

- CF128 신규 18개 포함 관련 8파일 단위·권한·저장·출력 회귀: 114 PASS, 0 FAIL, 0 SKIP.
- 원본 파일 브라우저 메모리 파서/작업용 왕복/공식 캐시 비사용/공격 입력 거부: 34 PASS. 격리 저장 회귀: 16 PASS. 운영 데이터베이스에는 실행하지 않았다.
- 구조 전용 원본 추출 메타로 17시트 인쇄영역·배율·여백·병합·글꼴·바닥글을 독립 비교했다. 메타 미제공 환경에서는 이 테스트가 명시적으로 SKIP되므로 원본 대조 PASS로 해석하면 안 된다.
- 실제 App 로컬 합성 API 브라우저: A4 41페이지, 4/4. 각각 443행이 정확히 한 번 포함됨, 전체/발췌 PDF 생성. 사용자 로그인 서버 UI 및 물리 프린터 실행과는 별개 증거다.
- 2차 브라우저에서 발견한 iframe 초기 documentElement null 경합은 보호 조건을 추가했다. 후속 좁은 범위 회귀 결과는 아래 최종 검증에 기록한다.
- 좁은 범위 회귀: 출력 초기화 3회·리사이즈 9회 오류 0, 원본 shrink 5셀 넘침 해소. 별도 PDF 텍스트 검사에서 3/3.의 긴 상태 문구가 종이 밖으로 이어짐을 발견해 ‘검토 필요’로 축약했다. 판정 의미와 화면의 미승인 경고는 유지한다.
- 최종 결함 국소 검사 PASS: 목록 SVG의 EMU 좌표를 CSS px로 변환해 브라우저 글꼴 크기 제한 문제를 해소했다. 실제 PDF 제목 높이 20.443pt/폭 92.911pt로 읽을 수 있음을 확인했다. 최신 41쪽 PDF 전체 한글 텍스트 추출·빈 본문 없음·종이 밖 텍스트 0·런타임 오류 0. 최종 PDF와 목록 페이지 렌더를 직접 확인했다.
