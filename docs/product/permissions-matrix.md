# 역할 기반 권한 매트릭스 명세서 (Permissions Matrix)

## 1. 사용자 역할 정의 (6대 표준 역할)
1. **대표 (CEO)**: 사업장 전체 관리자 및 최종 결재권자
2. **본부장/센터장 (Director)**: 부서/조직 관리자
3. **PM (Project Manager)**: 사건 총괄 담당자
4. **실무자 (Staff)**: 배정 사건 작성자
5. **검토자 (Reviewer)**: 법률 및 전문 검토자 (댓글 작성/수정요청/1차승인/승인취소 담당)
6. **시스템 관리자 (Admin)**: IT 및 보안 설정 관리자

## 3. 검토자(Reviewer) 권한 명확성 및 정합성 규칙 (Personas-RBAC 100% Alignment)
1. **자료/회의록 업로드**: 검토자(Reviewer)는 검토 참고자료 및 검토 의견서를 업로드할 권한이 허용됩니다 (**O**).
2. **본문 직접 편집 금지**: 검토자는 보고서 초안의 본문을 직접 수정하는 권한이 차단되며 (**X**), 문단별 inline 댓글 작성 및 [수정 요청]을 통한 2인 교차 검수를 진행합니다.
3. **1차 승인 및 승인 취소**: 검토자는 본인이 담당한 장(Section)의 1차 승인 및 승인 취소/검토 재개 권한을 가집니다 (**O**).
4. **최종 병합 출력 권한 차단**: 승인 완료된 장들을 결합하여 최종 DOCX/PDF 문서로 출력하는 기능은 사업장 결재권자인 대표, 본부장, 담당 PM에게만 부여되며 검토자에겐 차단됩니다 (**X**).

## 4. 데이터 접근 경계 제약 규칙
1. **조직 데이터 격리**: 본부장/센터장은 본인이 속한 센터/본부 소속 사건만 접근할 수 있습니다.
2. **배정 사건 격리**: PM 및 실무자는 본인이 담당자로 배정된 사건의 데이터 및 파일만 조회/수정할 수 있습니다.
3. **직접 URL 접근 차단**: 권한이 없는 사건/보고서 상세 URL로 직접 진입 시 가드(Guard) 인터셉터가 진입을 차단하고 403 Forbidden 안내 화면으로 리다이렉트합니다.
4. **금액/비용 수정 통제**: 성공보수 및 계약금액 수정 권한은 대표, 본부장, 담당 PM으로 엄격히 제한됩니다.
