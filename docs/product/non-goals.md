# 제품 비목표 및 통제 범위 명세서 (Non-Goals)

## 1. 개요
본 시스템의 기능적 경계와 안전 통제 범위를 명확히 정의함으로써, 잘못된 자동화나 오용으로 인한 법적·재무적 위험을 사전 방지합니다.

## 2. 제품 비목표 (Non-Goals)

### 1. 자동 소송 대리 및 법률 결론 자동 확정 금지
- 본 시스템은 법률 조언이나 소송 판단을 대신하는 자동 솔루션이 아닙니다.
- AI가 승소 가능성, 최종 법적 결론, 법원 판결 결과를 자동으로 결정하거나 확정하지 않습니다.

### 2. AI 근거 없는 핵심 데이터 임의 생성 금지
AI는 다음 11개 핵심 데이터 항목을 임의로 생성(Hallucination)할 수 없습니다.
- 사건번호
- 당사자 성명 및 신원 정보
- 계약금액 및 청구 금액
- 법원 기일 및 계약 날짜
- 법령 조항 및 판례 인용
- 계약 조항 및 면책 조건
- 손해액 산출 결과
- 성공보수 산출액
- 승소 가능성 수치
- 법적 책임을 확정하는 문구
- 근거 서류에 존재하지 않는 사실관계

### 3. 검토자/사람 없는 완전 자동 최종 문서 발행 금지
- AI가 생성한 문단은 담당자 및 검토자의 명시적 수정·검토·승인 없이 `최종 확정` 상태로 전환되거나 PDF/DOCX로 자동 출판될 수 없습니다.

### 4. 영구 파괴 삭제 금지
- 데이터베이스 및 파일 저장소에서의 모든 삭제는 소프트 삭제(Soft Delete)로 처리되며, 감사로그에 보존되어야 합니다. 원본 증거 및 이전 버전 파일의 무단 덮어쓰기나 영구 파괴 삭제를 제공하지 않습니다.

### 5. API 키 및 민감 클라이언트 노출 금지
- AI 공급자 API 키 및 서비스 계정 비밀번호는 클라이언트 JavaScript 번들, 브라우저 LocalStorage, 서버 로그에 절대 기록되거나 노출되지 않도록 고안됩니다.
