# ES 노임·지수·요율 API 발급 및 연결 가이드

확인일: 2026-09-10. 대상은 development 테스트 서버입니다. CF136에서 조달청 요율표·대한건설협회 일반공사 노임 수집, CF137에서 기계경비·5개 분야 표준시장단가 기간쌍 조회를 추가했습니다. 적용 범위와 검증 결과는 `docs/runbooks/cf136-es-public-sources.md`, `docs/runbooks/cf137-es-pair-sources.md`를 확인하세요. 키 원문과 고객 원본은 포함하지 않습니다.

## 1. 지금 준비할 인증값

| 구분 | 준비할 것 | 가져올 자료 | 현재 프로그램 상태 |
| --- | --- | --- | --- |
| 한국은행 ECOS | **발급받은 Open API 인증키 등록** | 광산품·공산품·전력/수도/가스 등·농림수산품의 월별 생산자물가지수 | 관리자 설정 → 한국은행 ECOS → 저장·연결 확인. ES 요율정보 가져오기와 연결 |

국가법령 OC는 법령 원문 조회 인증값이지, ES의 모든 숫자를 반환하는 통합 요율 키가 아닙니다. 법령 API는 행정규칙 본문과 별표 링크 등을 제공하므로 항목별 수치 해석과 시행일 매핑이 별도로 필요합니다. [공식 행정규칙 본문 API 안내](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=admrulInfoGuide)

### ECOS 발급 순서

1. [한국은행 ECOS Open API](https://ecos.bok.or.kr/api/)에 접속합니다.
2. 사이트의 인증키 신청 절차를 따릅니다. 회원가입·로그인 등 본인 확인은 사용자가 직접 진행합니다.
3. 이용 목적에는 다음과 같이 적을 수 있습니다: **사내 건설공사 물가변동(ES) 산출을 위한 생산자물가지수 월별 조회 및 기준일·조정일 비교**.
4. 서비스 주소를 요구하면 개발 서버 주소 `https://concost-claim-center-development.jjwwhhjj1116.workers.dev`를 입력합니다.
5. 발급된 인증키는 관리자 설정의 **한국은행 ECOS API 인증키** 칸에 저장하고 연결 확인을 누르세요. 국가법령 OC 칸에 넣지 마세요. 채팅에는 원문 대신 발급·등록 완료 여부만 알려주세요.

한국은행은 Open API 홈페이지에서 인증키를 먼저 발급받고 개별 서비스 명세를 확인하는 방식을 안내합니다. 정확한 현재 화면의 메뉴 위치는 로그인 후 확인이 필요합니다. [한국은행 ECOS 이용 소개](https://www.bok.or.kr/portal/bbs/B0000522/view.do?menuNo=201692&nttId=10070977)

### 기존 국가법령 인증값 확인

- 기존 관리자 설정의 국가법령 OC를 사용합니다. 다른 서비스의 키로 교체하지 않습니다.
- 공동활용 신청 내역에서 판례만이 아니라 **법령 본문·연혁, 행정규칙 본문·연혁 및 별표** 등 필요한 서비스의 사용 가능 범위를 확인합니다.
- 현재 법령만 조회하면 과거 입찰 기준일의 요율을 잘못 적용할 수 있습니다. 공포일과 시행일을 구별하고 해당 날짜에 효력이 있는 원문을 선택해야 합니다.
- 건강·연금·장기요양, 고용·산재, 퇴직공제, 산업안전보건관리비는 분모·부담 주체·등급·공종 조건이 서로 다릅니다. 예를 들어 전체 보험료율과 사업주 부담률, 건강보험료 대비 장기요양 비율을 섞으면 안 됩니다. 이 가이드는 특정 계약의 법적 적용률을 확정하지 않습니다.

공식 서비스 범위: [행정규칙 목록·연혁 API](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=admrulListGuide), [행정규칙 본문 API](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=admrulInfoGuide).

## 2. 공식 파일 수집과 남은 범위

노임은 CF136에서 공개 HWPX 자동 수집을 연결했습니다. CF137은 기계경비 공식 PDF와 조달청 표준시장단가 XLS/XLSX 총괄표를 추가 키 없이 조회합니다. 공식자료 자동조회 → 현재값과 비교 → 확인 후 적용 → 저장·계산 순서이며, 취소·기존 기간쌍 유지·적용 후 수동 수정이 가능합니다.

| 항목 | 공식 자료 경로 | 필요한 연동 |
| --- | --- | --- |
| 건설 노임 | [대한건설협회 2026 하반기 공식 HWPX](https://www.cak.or.kr/download.do?uuid=173735f5-cd8d-45d4-8d8f-ffc0968f8500.hwpx) | CF136 자동 연결. 원본 T열과 같은 일반공사 평균을 공표일별 선택. 조사월과 적용일을 구별 |

자동 수집은 기관 이용 조건·허용 범위를 확인한 후 구현합니다. 접근이 제한되거나 자료 형식이 바뀌면 관리자 원문 업로드로 보완하고 검증되지 않은 숫자를 자동 적용하지 않습니다. AI는 원문 탐색·추출 보조만 하고, 산출에 쓰는 숫자는 원문 대조와 결정적인 규칙으로 확정합니다.

[KOSIS 공유서비스](https://kosis.kr/openapi/)는 인증키 신청 절차를 제공하지만, 키 발급 자체가 필요한 ES 자료의 존재나 일치를 보장하지 않습니다. 먼저 통계표와 단위를 확정해야 합니다.

## 3. 다시 확인한 원본 Excel의 실제 동작

사용자가 제공한 원본을 읽기 전용으로 확인했습니다. 파일을 저장·수정하지 않았습니다.

- `기본입력!I5`: 초회일 때 `C10`, 그 외 `C13` 기준일 선택.
- `J5`: 조정기준일 `C12 - 1`, `K5`: `C12`.
- `I8` 등 노임: 해당 연월을 `R5:Y88`에서 정확히 찾습니다.
- `I10` 등 재료지수 적용월: 기준일이 그달 말일이면 당월, 그 외에는 전월을 선택합니다. 현재 웹은 실제 달력을 사용합니다.
- `I11:I14` 등: 위 선택 월의 재료지수를 찾습니다. `U3`의 기준년 표시는 **2020=100**입니다.
- `I18`: 산업안전 요율은 `C22`를 참조합니다. 화면의 1.86이 유지된 것은 모든 외부 조회가 성공했다는 뜻이 아닙니다.
- 원본 이력 `R5:R88`은 **2019년 1월~2025년 12월**입니다. 뒤쪽 일부 재료지수는 비어 있습니다. 따라서 이 범위만 가져와서는 **2026년 자료가 자동으로 생기지 않습니다**.

현재 화면 예시가 기준일 2024-06-15 / 조정일 2026-05-01이라면 아래 기간을 조회해야 합니다. 이는 원본/현재 웹의 선택 규칙 설명이며, 특정 계약의 적용 기준 승인과는 별개입니다.

| 비교 구분 | 적용일 | 노임·산재 참조월 | 재료지수 참조월 |
| --- | --- | --- | --- |
| 기준 | 2024-06-15 | 2024-06 | 2024-05 |
| 직전 | 2026-04-30 | 2026-04 | 2026-04 |
| 조정 | 2026-05-01 | 2026-05 | 2026-04 |

노임은 각 월에 유효한 공표분을 연결해야 하며 월별 신규 조사값이라는 뜻이 아닙니다. ECOS 통계도 원본과 동일 계열·2020=100·단위·월 주기를 확인해야 합니다. 서로 다른 기준년을 섞지 않습니다. [한국은행 생산자물가 2020년 기준년 개편 안내](https://www.bok.or.kr/portal/bbs/B0000501/view.do?menuNo=201263&nttId=10084099)

## 4. 프로그램 연결 구현 기준 및 남은 범위

CF136은 ECOS·법령에 조달청 및 대한건설협회 공개 파일 조회를 병렬로 연결하고, 확인창에서 직접 수정·기존값 유지·취소를 지원합니다. 조달청 공표 이력은 2023-01-02부터, CAK 역사표는 2015-01-01부터 연결했으며 검증 기준일 2026-09-10 이후의 자료를 현재값으로 추정하지 않습니다. 새 공표본은 catalog 확인·갱신이 필요합니다.

산업안전보건관리비는 공사종류·대상액·기초액에 따라 달라지는 조건표이므로 원본 C22 공통값을 유지합니다. 사용자는 ‘조건 2’ 지정을 철회했으며, 이를 2%로 해석하거나 기존 1.86%를 임의 변경하지 않습니다. 계약금액을 대상액으로 간주하지 않습니다. CF137 기간쌍은 확인된 2023~2026 공표본까지 지원하며, 미연결 기간은 Excel·수동 입력을 유지합니다. 후속 차수 계산 확대는 이번 범위 밖입니다.

1. 관리자 설정: ECOS 키 암호화 저장·교체·연결 확인, 기존 법령 OC 재사용. 브라우저/로그/소스에 키를 노출하지 않음.
2. ECOS 계열 매핑: 원본의 4개 분류와 공식 항목 코드·기준년을 고정하고 과거 월까지 조회. 코드 확인 전 임의 항목을 사용하지 않음.
3. 노임/표준시장단가/기계경비 공식 파일 수집과 요율별 법령 파서, 적용기간 이력 저장.
4. 날짜·등급·공종 변경 시 기존 자료를 ‘재조회 필요’로 표시하고, **ES 요율정보 가져오기**로 세 시점의 검증된 후보를 조회.
5. 확인창에 요청일·선택월·원문/공표일/시행일·단위·현재값/후보값을 나란히 표시. ‘미연결 / 키 없음 / 조회 실패 / 해당 기간 미공표 / 원문 검증 필요’를 구별.
6. 조회 실패나 빈 후보는 동일 적용일의 기존 수동값을 덮어쓰지 않음. ECOS 성공 시 재료지수 4종만 변경. 날짜가 다른 값을 재사용하지 않으며 확인 전 취소하면 입력은 유지됨.
7. 확인 후 입력에 적용 → 저장·계산 → 17시트 출력. 비목별 계약 금액·적용대가·기성·선금 등 회사 계약 정보는 공공 API에서 채울 수 없음.

### 완료 판정에 필요한 시험

- 2024/2026 등 두 기간의 원문 수치와 API 수치 비교, 월말/월초·윤년 선택 시험.
- 법령 시행일 전날/당일, 등급·공종 변경, 전체율/사업주분·분모·단위 검증.
- 미발표·중복 자료·인증 오류·타임아웃은 자동 대체하지 않고 이유 표시.
- 적용 취소/부분 성공/수동값 보존, 저장 후 재열기, 원문 해시·조회 이력 확인.
- 동일 입력으로 원본 계산과 K·공제·최종 금액·17시트 출력 비교.

확인창은 자동조회·기존/Excel 값 유지·수동 입력 필요를 구별하고 항목별 출처·조건을 보여줍니다. 자동조회 결과는 적용 전 후보이며, 사용자의 계약상 적용 확인이나 공식 제출 승인을 대신하지 않습니다.
